# 🦀 Claw'd — a Claude Code desktop pet

A pixel crab (an original take on Anthropic's Claw'd mascot) that lives on your desktop, watches every Claude Code session on the machine, and tells you when a conversation is ready to move on.

Forked from [ClaudeCodePet](https://github.com/WangJunqing-coder/ClaudeCodePet) (MIT). Sprite art is generated by our own scripts — nothing is copied from other pet projects.

## What it does

- **Watches Claude Code** — hooks report every session's tool calls, prompts and turn endings. The crab pulls out a laptop and types while Claude works, jumps when a turn finishes, blinks when Claude is waiting for you.
- **Reminds you to move on** — when a run longer than 15 s ends you get a system notification: *“Ready to move on — 「project」”*. Quick chat turns stay silent.
- **Click → today's spend** — runs [ccusage](https://github.com/ryoppippi/ccusage) offline and shows the API-equivalent cost for today plus token counts.
- **Roams** — strolls along the bottom edge, climbs up the screen sides, hangs out on the wall, smells a flower, falls back down when you drop it mid-air. Right-click → *Roam* to toggle.
- **Gets out of the way** — when a borderless fullscreen app (game, video) is in front, it tucks half off the right edge and becomes click-through. Comes back when the app closes. Tray → *Tuck to edge* does the same manually.
- **Tray icon + Start with Windows** (packaged build).

## Run

```bash
npm install
npm start                 # dev
npm run hooks:install     # register Claude Code hooks in ~/.claude/settings.json (reversible)
npm run build             # dist/Clawd-win32-x64/Clawd.exe
```

`hooks:uninstall` removes the hooks again (a backup is written to `settings.json.ccpet-bak`).

## Art

`assets/make_clawd_sprites.py` renders the whole sheet (Codex Pet Standard: 8 cols × 192×208, rows 0–8 standard, rows 9 `typing` / 10 `flower` are extensions) plus `icon.ico`/`tray.png`. Run it with the project's Python env (`30_Tools/py311`). `make_crab_sprites.py` is the rounder alternative skin (`renderer/spritesheet-round.webp`).

## Layout

```
main.js                     Electron main: window, tray, HTTP status server, ccusage, fullscreen watcher
preload.js                  IPC bridge
renderer/pet.js             animation engine, roaming/climbing/hiding, menu
renderer/spritesheet.webp   generated sprite sheet
hooks/notify.js             Claude Code hook → POST http://127.0.0.1:31126/status
scripts/setup-hooks.js      install/uninstall hooks
scripts/fullscreen-watch.ps1  foreground-window watcher (prints FS:0/FS:1)
assets/make_clawd_sprites.py  sprite + icon generator
```

## Manual status push

```bash
curl -X POST http://127.0.0.1:31126/status -H "Content-Type: application/json" -d "{\"status\":\"running\",\"message\":\"hello\"}"
```

Statuses: `idle` · `running` · `waiting` · `completed` · `error`.
