# 🦀 Claw'd — a Claude Code desktop pet

[English](README.md) · [简体中文](README.zh-CN.md)

A pixel crab that lives on your desktop, watches every Claude Code session on the machine, and tells you when a conversation is ready to move on.

<img src="docs/demo.gif" width="200" align="right" alt="Claw'd animating">

- **Watches Claude Code** — hooks report tool calls, prompts and turn endings. The crab pulls out a laptop and types while Claude works, reads along with a magnifier during file searches and hammers a terminal during shell runs.
- **Reacts to what Claude does** — crosses its fingers while your tests run, hops with a halo when they pass, sits under a rain cloud when they fail, summons a mini crab for each batch of subagents, and celebrates finished turns (a hop, a dance, or shades after a clean streak). *Reactions: Off* in the menu turns these off.
- **Tells you when to come back** — a run longer than 15 s ends with a notification: *"Ready to move on — project is ready for you"*. Quick chat turns stay silent.
- **Dresses up** — a wardrobe of hats: seasonal ones on Auto (Santa at Christmas, cat ears around Halloween, a beanie on winter mornings), a hard hat and a headband on long runs, a wizard hat in plan mode — or pick your own.
- **Click → this week's spend** — a small card with the API-equivalent cost per day (Mon–Sun) over tokens per day, via [ccusage](https://github.com/ryoppippi/ccusage) (offline pricing, nothing leaves your machine). `ccusage-pricing.json` adds list prices for models newer than ccusage's own table, so they don't count as $0.
- **Roams your desktop** — strolls the bottom edge, climbs the screen sides, naps, snacks by time of day, and falls back down if you drop it mid-air.
- **Stays out of the way** — when a fullscreen app is in front it climbs the right edge and slides its lower half off-screen, so just its head peeks in — click-through, headphones on, gamepad in hand.
- **Keeps you company** — hover to pet it (hearts), wiggle the cursor over it to tickle it, its eyes follow your cursor when you're near, a stretch reminder after 50 minutes at the keyboard, and a badge when several Claude sessions run at once.
- **Has a physical body** — pick it up and it dangles (and panics if you swing it around), drop it and it lands with a squash, fling it and it flies, bounces off the screen edges, tumbles and lands dizzy (throw it three times and it gets angry). It also climbs up the side of the Claude window (or whatever you're working in) and sits on the title bar for a while.
- **Eats files** — drag a file over it and it opens its lid; drop it and it munches it and tells you what it tasted: *"Crunchy! pet.js: 1,870 lines, 64 KB"*. Only the size and line count are read.
- **Is a little bit of trouble** — leaves muddy claw prints that fade, and when you step away for a minute it may sneak over and run off with your mouse cursor. Move the mouse and it lets go at once. *Mischief: Off* in the menu turns both off.

## Animations

All 43 animations are generated by `assets/make_clawd_sprites.py` — no external art, no traced assets. The same script draws the 17 emotes (small marks that pop up next to the head: `!`, `?`, a light bulb, sweat drops, hearts, a rain cloud, tool icons…) and the 12 hats.

![Animation set](docs/animations.png)

Rows 0–21 are the original set (idle, walking, waving, jumping, typing, snacks, gaming, backflip, dozing, sleeping, stretching, petted…). Rows 22–42 are new: `look`, `hop`, `dangle`, `dizzy`, `surprised`, `plotting`, `yawn`, `love`, `laugh`, `nervous`, `fingers-crossed`, `sad`, `summon`, `chomp`, `furious`, `work-read`, `work-shell`, `dance`, `cool`, `trot` and `fall`, plus eight variants cut from them (`hop-land`, `dangle-scared`, `startle`, `busted`, `summon-return`, `chomp-open`, `trot-stop`, `squint`).

### Watching Claude Code

| Trigger | What it does |
| --- | --- |
| Claude is working | types on a laptop; after a run of Read / Grep / Glob calls it reads with a magnifier, after Bash calls it types into a terminal (each pose holds at least 8 s); sips coffee every 25 min on long runs |
| New prompt | a light bulb pops up next to "Thinking..." |
| A different kind of tool | a small tool icon (at most once per 30 s) |
| Tests start (`npm test`, `pytest`, `cargo test`, `go test`, …) | fingers crossed |
| Tests pass | hops and wears a halo for 10 s |
| Tests fail | a rain cloud and "Tests failed. We got this." |
| Subagents start / all are back | a mini crab pops out of a puff / goes back in |
| `git commit` / `git push` | a green check / a sparkle |
| Claude needs a decision | blinks and waits, the bubble stays until you act; gets nervous after 30 s |
| Back after 20+ min without Claude | startled |
| Context compacted | chomps: "Munched the old context!" |
| `/clear` / a resumed session | "Fresh start!" / waves: "Welcome back!" |
| Turn finished | a hop for quick turns, a jump, backflip or dance for longer ones; sunglasses after a clean streak |
| Long run / plan mode | a hard hat after 2 min, a headband after 8 min / a wizard hat |

With several sessions open, only the one you prompted last drives these (a permission prompt from any session still gets through). *Reactions: Off* in the menu turns this whole table off, except the plain typing / waiting / jumping it always did; the desktop behaviour above stays on.

The reactions need the hook from this version: see [Updating](#updating). With an older `hooks/notify.js` the crab just types, waits and jumps as before.

## Install

Grab the packaged app from [Releases](../../releases) — unzip and run `Clawd.exe` (Windows x64, no installer).

Then register the Claude Code hooks so the crab can see your sessions:

```bash
npm run hooks:install
```

This adds seven hooks to `~/.claude/settings.json` (a backup is written to `settings.json.ccpet-bak`) and takes effect for newly started Claude Code sessions. To undo:

```bash
npm run hooks:uninstall
```

> The hooks point at this folder's `hooks/notify.js`, so keep the repo where it is (or re-run `hooks:install` after moving it).

### Updating

`hooks/notify.js` runs on every tool call of every Claude Code session, so a new version of it ships next to it as `hooks/notify.next.js` and is swapped in by a script instead of being edited in place:

1. Quit Claw'd from its menu.
2. `npm run build`, then start `dist/Clawd-win32-x64/Clawd.exe` again.
3. Activate the new hook:

   ```bash
   node scripts/activate-notify.js
   ```

   It copies `notify.next.js` to `notify.js.new`, syntax-checks it, pipes a sample event through it (to the unused dev port 31127, never to the pet), keeps the current hook as `hooks/notify.prev.js` (only on the first activation; running the script again when `notify.next.js` is already active does nothing), and renames the new file over `hooks/notify.js` (retrying for a moment if a running hook holds the file). `node scripts/activate-notify.js --rollback` puts the previous hook back.
4. Make any tool call in Claude Code and check that `http://127.0.0.1:31126/status` shows it.

The new hook only adds short tags to what it sends (the tool kind, `test` / `git-commit` / `git-push` for a shell command, a pass / fail verdict for a test run, the notification type, the permission mode), never command text, prompts or output. It also sends its bubble texts in English.

**Optional, your call:** three more hook events would make the test-failure and usage-limit reactions reliable — `PostToolUseFailure` (today a failing test is inferred from the next event), `StopFailure` and `PreCompact`. Nothing registers them automatically (`hooks:install` registers the seven events above). To add them, put entries like this into the `hooks` of `~/.claude/settings.json`, with the same path as your other Claw'd hooks:

```json
"PostToolUseFailure": [{ "matcher": "", "hooks": [{ "type": "command", "command": "node \"<repo>/hooks/notify.js\" PostToolUseFailure", "timeout": 10 }] }],
"StopFailure": [{ "hooks": [{ "type": "command", "command": "node \"<repo>/hooks/notify.js\" StopFailure", "timeout": 10 }] }],
"PreCompact": [{ "hooks": [{ "type": "command", "command": "node \"<repo>/hooks/notify.js\" PreCompact", "timeout": 10 }] }]
```

Re-running `hooks:install` removes them again.

## Run from source

```bash
npm install
npm start          # dev
npm run build      # dist/Clawd-win32-x64/Clawd.exe
```

Requires Node.js 18+. Windows only for now — the fullscreen watcher and start-with-Windows use Win32 APIs; the rest is portable.

## Using it

- **Left click** — this week's cost curve and tokens per day; hover a day for its numbers, click the card to close it
- **Double click** — bring the Claude desktop app to the front (launches it if it isn't running)
- **Drag** — move it; drop it in mid-air and it falls; let go while moving fast to throw it
- **Hover** — petting; wiggle the cursor across it to tickle it
- **Drop a file on it** — it eats it and tells you the size and line count
- **Right click / tray icon** — usage, roaming, hide at screen edge, mischief, reactions, tricks, wardrobe, start-with-Windows, restart, quit

The right-click menu:

- **🔔 Reactions: On / Off** — the Claude Code reactions (see [Watching Claude Code](#watching-claude-code)). Saved in `pet-config.json`.
- **🎭 Tricks** — wave, jump, backflip, think, flower, snack, nap, 💃 dance, 😎 be cool, 😲 boo!, 🍱 chomp, 💕 love, 😪 yawn, and fling me / perch on a window / steal the cursor.
- **👒 Wardrobe** — *Auto (seasonal)* (the default: Santa hat Dec 20–26, party hat on New Year's Eve and Day, cat ears Oct 25–31, a bow on Feb 14, a beanie on winter mornings, plus the work hats of long runs and plan mode), *None*, or a fixed hat: party hat, top hat, crown, beanie, Santa hat, wizard hat, cat ears, bow, shades, hard hat. Saved in `pet-config.json`; greyed out while an imported pet is on.
- **🦀 Built-in Claw'd** — only while an imported pet is on: back to the crab.

"Hide at screen edge" makes the crab climb the right edge and hang there with its lower half off-screen, click-through, so it is visible but never in the way — the same thing it does by itself when a fullscreen app is in front.

## If the crab disappears

It looks after itself:

- **Renderer crash or hang** — the window reloads itself, backing off if it keeps crashing.
- **Running `Clawd.exe` again** while it is up brings a lost crab back (dead window, off-screen) instead of doing nothing.
- **The whole app died** — the next Claude Code hook event relaunches it (at most every 2 minutes), unless you quit it from the menu.
- **Quit from the menu** keeps it off until you start `Clawd.exe` again or the next Windows sign-in, where *Start with Windows* brings it back (untick that to keep it off across restarts). Ending `Clawd.exe` in Task Manager counts as a crash, so the hooks bring it back.
- **Alt+F4** on the crab is ignored; quit from the menu instead.
- **Start with Windows** writes a quoted path to the Run key, so a stray file named like the first part of a path with spaces can't hijack logon.

To find out why it went away, read `logs\clawd.log` next to `Clawd.exe` (starts, quits, crashes, recoveries, and "previous run ended without a clean quit"; `npm run build` recreates `dist/`, so a rebuild starts a fresh log), or run the read-only check (in a release zip it is `resources/app/scripts/doctor.ps1`):

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/doctor.ps1
```

## Sprite art

`assets/make_clawd_sprites.py` renders the whole sheet plus `icon.ico` / `tray.png`; `assets/make_preview.py` renders the images in this README. Both need Python 3.11+ with Pillow.

The sheet follows the Codex Pet Standard (8 columns × 192×208 cells): rows 0–8 are the standard set, rows 9–42 are this project's extensions. The generator also writes `renderer/emotes.webp`, `renderer/hats.webp` and `renderer/clawd_meta.js` (frame timings, variants, and the head / eye anchors the hats and emotes are placed on). Replacing `renderer/spritesheet.webp` swaps the character; the right-click menu can also import a `.zip` pet pack. A pack with fewer rows still plays every animation: each new row falls back to one of the rows 0–8 (hats are off for imported pets).

## How it works

```
Claude Code hook ──> hooks/notify.js ──POST──> 127.0.0.1:31126/status
                                                      │
                                            main.js (Electron main)
                                        window · tray · ccusage · watchers
                                                      │ IPC
                                            renderer/pet.js
                                     animation engine · roaming · menu
```

| Path | Role |
| --- | --- |
| `main.js` | window, tray, HTTP status server, ccusage, fullscreen + idle watchers |
| `ccusage-pricing.json` | ccusage price overrides for models its built-in table doesn't know yet |
| `preload.js` | IPC bridge |
| `renderer/pet.js` | animation engine, the reaction director (who gets to pick the row: a gesture, a prompt waiting for you, a test result, the work pose, an idle snack), roaming/climbing/hiding, menu actions |
| `renderer/overlay.js` | where a hat or emote goes on each frame (pure maths, shared with the QA preview) |
| `renderer/clawd_meta.js` | generated: rows 22–42, variants, anchors, emote and hat tables |
| `hooks/notify.js` | maps hook events to `idle` / `running` / `waiting` / `completed` / `error` |
| `hooks/notify.next.js` | the next `notify.js`: adds the reaction tags; activated by `scripts/activate-notify.js` |
| `scripts/setup-hooks.js` | install / uninstall the hooks |
| `scripts/activate-notify.js` | swaps `notify.next.js` in as the live hook (checked, backed up, `--rollback`) |
| `scripts/fullscreen-watch.ps1` | window watcher: fullscreen state (`FS:`) and window geometry for perching (`WIN:`) |
| `scripts/cursor-helper.ps1` | moves the mouse cursor for the cursor-stealing trick |
| `scripts/focus-claude.ps1` | brings the Claude app to the front / launches it |
| `scripts/doctor.ps1` | read-only health check: process, window, start-with-Windows entry, hooks, log, Windows crash events |
| `renderer/trail.*` | click-through overlay that draws the fading footprints |

Push a status by hand:

```bash
curl -X POST http://127.0.0.1:31126/status -H "Content-Type: application/json" -d "{\"status\":\"running\",\"message\":\"hello\"}"
```

`GET /status`, `GET /health`, `GET /usage`, and `POST /action`, `/fullscreen`, `/idle`, `/restart`, `/debug/crash-renderer`, `/debug/usage` (show the card with canned data; `null` restores) are also available on localhost for testing.

When run from source (or with `CLAWD_DEBUG=1`) there are also QA routes under `/debug/` (`anim`, `hook`, `emote`, `hat`, `date`, `cursor`, `skin`, `state`, `capture`, `drop`); each one needs the header `X-Clawd-Debug: 1`, so a web page can't call them. A second, dev copy of the pet runs next to the real one with `tools/qa/dev/start_dev.ps1` (port 31127, its own profile, mischief and roaming off) and stops with `tools/qa/dev/stop_dev.ps1`; `CLAWD_PORT=31127 node hooks/notify.next.js PreToolUse < event.json` feeds it a hook event.
